---
name: Presentation generation
description: Durable convention for creating presentation deliverables in this workspace.
---

Use an editable PowerPoint as the primary presentation deliverable when a user asks for a slide deck, embedding real product screenshots and keeping diagrams/text editable.

**Why:** Executive presentations benefit from both visual evidence and the ability to revise messaging in Google Slides or PowerPoint.

**How to apply:** Generate with the workspace’s ES-module Node configuration, validate the `.pptx` ZIP structure and slide count, then present the file as an asset.
