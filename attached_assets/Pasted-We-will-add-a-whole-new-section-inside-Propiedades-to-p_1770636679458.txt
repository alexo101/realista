We will add a whole new section inside Propiedades to power Property Management.
In the "Propiedades" table we will have 3 new columns: 
- "Estado": that will be a new field  associated to the properties that can take the following values: Creada, Activa, Reservada, Alquilada, Inactiva, Vendida, En reforma. Upon clicking "Cambiar estado" a modal will pop-up point current status and the dropdown to change and a button "Confirmar cambio"
- "Tipo de Operación": Based on the value selected in the field of the same name
- "Inquilino": showing the name of the selected inquilino, empty with a "-" if none client has been selected

The biggest change comes inside the property profile after clicking the icon to see the details of the property. Inside we will have 7 tabs as in the image. By clicking on "Editar datos" we land in the flow to edit the property. By clicking "Cambiar estado" we change the "estado" of the property as specified above. The price of the property will be displayed also. In the top left the user will see a button to go back to propiedades "Volver a propiedades"

In the tab "Resumen" (image 1) the user will see
- the next payment date based on the dates settled in the Alquiler section. If the property is a Sale property the card will be empty showing a "-"
- open incidences. the data will be fetch from the info added in the "Incidencias" tab.
- details of the property
- Agenda with a preview of the events from Calendario related to the property and events created in the Comunicaciones tab.

In the tab "Incidencias" (image 4) will be recorded the incidences related to the property. Upon clicking "Nueva incidencia" button a modal will open with the fields 
"Titulo" capped on 50 characters
"Estado" that can take the values: Nueva, Asignada, En espera, Resuelta, Verificada, Cerrada
"Prioridad" that can take the values: Alta, Media, Baja
"Descripción with a text box capped to 500 characters
Upon clicking "Registrar incidencia" the incidence will be added to the table of incidences as in the image. Upon clicking the button to edit the modal will open and the dropdown arrow will show the description and a confirmation snack bar will appear

In the tab Comunicaciones (image 5) the agent will record the communications sent to the tenant. It will not work to send the communications natively but more like an agenda of Communications
Upon clicking "Nueva comunicación" a modal will open with the following fields
"Titulo" capped to 50 characters
"Tipo de comunicación" that can take the following values: Actualización renta, Desalojo, Devolución de fianza, Entrega de llave, Finalización de contrato, Incidencia en la propiedad, Inclusión en fichero de morosos, Inspección de propiedad, Mantenimiento, Obras, Pago suministro, Reparación, Retraso de pago
"Fecha relevante" that upon clicking will open a calendar to select a date
A check "Añadir a calendario" that if checked the Communications event will be 
displayed in the "Calendario" tab. The calendar must accept this type of event.
Descripción which would be an optional field
A check "Añadir a historial" to select important communications that will appear later in the "Historial" tab
The modal will have buttons to cancel and to proceed " Registrar comunicación". Upon clicking "Registrar comunicación" the Communication will be added to the table and a confirmation snack bar will appear

The last tab is "Historial" (image 6) where will be register chronologically all major events on the property and only the main info but not the detail.
